Mode dossier local

Clique sur Ouvrir le dossier ochane et choisis le dossier du site sur ton ordinateur (celui qui contient index.html). Tu modifies les fiches ici ; l'outil écrit directement data/place-details.js et les photos dans img/places/. Il ne reste ensuite qu'à faire le git push.

Fonctionne avec Chrome, Edge ou Brave sur ordinateur. Aucune donnée n'est envoyée sur Internet : tout reste sur ta machine. Une copie de sécurité de l'ancien fichier est enregistrée dans _travail/ à chaque enregistrement.
